# Лабораторна робота №1 — Node.js

## Кореляційний аналіз у задачах виявлення прихованих об’єктів

### Що використано

- Node.js 18+;
- вбудований `fetch` для HTTP-запитів;
- вбудований модуль `http` для локального веб-сервера;
- HTML/CSS/JavaScript для графічного інтерфейсу;
- HTML5 Canvas для побудови діаграм;
- власна ковзна взаємна кореляція без NumPy/SciPy та без готових DSP-функцій;
- усереднення `L = 4`.

Додаткові npm-пакети для запуску не потрібні.

## Запуск

Потрібен Node.js 18 або новіший.

```bash
npm start
```

Після запуску відкрити:

```text
http://localhost:3000
```

Для режиму розробки:

```bash
npm run dev
```

## Сервер ехолота

За замовчуванням використовується:

```text
https://ooi-lab1.up.railway.app
```

Маршрути:

```text
GET /api/config
GET /api/pulse
GET /api/sensor?step=<число>
```

Node.js сервер проксуює ці запити до сервера ехолота. Тому браузер звертається до `localhost`, а не напряму до зовнішнього API.

За потреби адресу можна змінити.

## Структура

```text
lab1/
├── package.json
├── server.js
├── README.md
└── public/
    ├── api.js
    ├── app.js
    ├── charts.js
    ├── correlation.js
    ├── index.html
    └── style.css
```

### `server.js`

Локальний HTTP-сервер Node.js. Він віддає HTML/CSS/JavaScript і проксіює `/api/*` до сервера ехолота.

### `public/app.js`

Координує інтерфейс, вимірювання та повне сканування маршруту.

### Модулі клієнта

- `api.js` — HTTP-запити до API ехолота;
- `correlation.js` — власна ковзна взаємна кореляція, пошук піку та усереднення;
- `charts.js` — малювання графіків через HTML5 Canvas.

## Як будується діаграма

Node.js сам по собі не є графічним середовищем. У цій реалізації Node.js відповідає за серверну частину, а браузер виконує `public/app.js`.

Після отримання сигналу JavaScript:

1. обчислює масив кореляції;
2. знаходить `kmax`;
3. розраховує затримку та відстань;
4. передає числові масиви функції `drawLineChart()`;
5. `drawLineChart()` використовує HTML5 Canvas для побудови лінійного графіка.

Тобто схема роботи така:

```text
Сервер ехолота
      ↓ HTTP
Node.js
      ↓ HTTP / HTML / JS
Браузер
      ↓
app.js
      ↓
кореляція + розрахунок
      ↓
HTML5 Canvas
      ↓
діаграма
```
